# Unity Maze Game

A simple 3D maze game developed using **Unity 6.3 LTS** and **C#** as part of a Game Development Lab project.

## Features

* 3D maze environment
* Keyboard-controlled player movement
* Physics-based wall collision
* Simple maze navigation

## Controls

* **W / Up Arrow** — Move Forward
* **S / Down Arrow** — Move Backward
* **A / Left Arrow** — Move Left
* **D / Right Arrow** — Move Right

## Technologies

* Unity 6.3 LTS
* C#
* Unity Physics System
